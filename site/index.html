Before you start

Requires iCloud+ and Apple ID sign-in with 2FA. An unofficial client of Apple’s web API.

01 / Everyday commands

One alias per service.
A label you can find later.

Create and choose

Pick from Apple’s candidates in your terminal.

ihme new github.com

Find the right address

Search your labels, addresses, and notes.

ihme list --search github

Stop unwanted mail

Deactivate an alias. Reactivate it if you need it again.

ihme deactivate github.com

Keep your own copy

Export addresses as CSV or JSON.

ihme export -o backup.csv

02 / When you want to automate

Script it.
Or ask an agent.

Direct commands work without an LLM. Use the assistant when a task is easier to describe.

Structured output

Get candidates without reserving. Choose one, then reserve it with --address. 

ihme new github.com --json

Address commands support JSON. --jq needs an installed jq.

Your existing coding agent

Use an installed, signed-in Codex or Claude. Or configure the built-in assistant with your model key. 

ihme agent --via codex \
  "find my github address"

03 / Get started

Install. Sign in.
List your aliases.

One binary. Your existing iCloud account. Sign-in is interactive; have your trusted device ready. 

curl -fL https://github.com/lroolle/ihme-cli/releases/latest/download/ihme_macOS_arm64.tar.gz -o ihme.tar.gz
tar -xzf ihme.tar.gz ihme
sudo install -m 755 ihme /usr/local/bin/ihme
ihme version

Run in your shell. This installs ihme in /usr/local/bin.

Then sign in 
ihme auth login
ihme auth status --json
ihme list

04 / Check the work

Small tool.
Open source.

CI runs lint, vet, tests, and a build. The tests cover authentication, session recovery, address operations, filtering, and agent consent using fixtures and mock servers.

Clone the repo and run make check to reproduce the code checks. They do not test Apple’s live service or guarantee access for your account.

View CI ↗Browse releases ↗Security ↗

A good fit for your existing aliases.

Use Apple’s settings or iCloud.com if you prefer an official interface. ihme is for terminal workflows, scripts, and exports. It needs iCloud+, uses an undocumented API, and is not a bulk address service. Apple controls access and rate limits.

Agent mode sends task context and tool results to your chosen provider. Direct commands do not use an LLM.
