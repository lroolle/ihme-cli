ihme

在终端里管理 iCloud 隐藏邮件地址。

ihme 是一个管理 iCloud 隐藏邮件地址的命令行工具。为一次注册生成一个地址，之后按标签找到它，不想再收信了就停掉。它还能把所有地址导出成 CSV 或 JSON，留一份不在 Apple 服务器上的备份。

ihme new github.com          # Apple 给几个候选地址，你选一个
ihme list --search github    # 按标签、地址或备注查找
ihme deactivate github.com   # 停止转发
ihme export -o backup.csv    # 导出一份自己的备份

三种用法。手动：跑一条命令，选一个地址。脚本：所有命令都支持 --json。agent：内置助手用你自己的模型 key，或者用你已经登录的编程 agent，改动账户之前会先问你。

需要 iCloud+ 订阅和开启了双重认证的 Apple ID。Apple 没有公开这个 API，ihme 用的是 icloud.com 网页版的同一套接口，Apple 随时可以改动或封掉它。

安装

macOS，Apple 芯片：

curl -fL https://github.com/lroolle/ihme-cli/releases/latest/download/ihme_macOS_arm64.tar.gz -o ihme.tar.gz
tar -xzf ihme.tar.gz ihme
sudo install -m 755 ihme /usr/local/bin/ihme

macOS Intel、Linux、Windows 的 arm64 和 x86-64 版本在 releases 页面，附 SHA-256 校验值。有 Go 的话：go install github.com/lroolle/ihme-cli/cmd/ihme@latest。

然后登录，查看自己的地址：

ihme auth login    # Apple ID、密码、双重认证码。会话会保存在本地，密码和验证码不保存。
ihme list
